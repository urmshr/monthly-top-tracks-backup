# Top Tracks Archiver

A script to save the month's top songs to a Spotify playlist at the end of each month.

## Environment variables

- `SPOTIPY_CLIENT_ID`
- `SPOTIPY_CLIENT_SECRET`
- `SPOTIPY_REDIRECT_URI`
- `SPOTIPY_REFRESH_TOKEN`
