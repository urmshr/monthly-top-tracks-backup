# My Top Tracks Archiver

A script to back up your top songs of the month to a private playlist at the end of each month.

## Environment Variables

- `SPOTIPY_CLIENT_ID`
- `SPOTIPY_CLIENT_SECRET`
- `SPOTIPY_REDIRECT_URI`
- `SPOTIPY_REFRESH_TOKEN`
